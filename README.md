# WarOfChronos
### 一个面向机房摸鱼与局域网联机的网页卡牌游戏

## 游戏背景
两个平行宇宙的人类文明爆发冲突，双方都掌握时间旅行能力，于是在各个时间线进行战斗，并通过各种手段篡改双方的时间线,并《适当》融入三体世界观

## 游戏规则
以下是游戏规则
### 胜利
双方初始持有一个防御力30的指挥部，率先摧毁敌方指挥部的一方胜利
### 战场
和KARDS相似，但是有五条阵线

-----总部A-----

-----缓冲区-----

-----前线-----

-----缓冲区-----

-----总部B-----

双方总部所在阵线叫做指挥阵线，指挥阵线无法被对方占领，其余三条战线均可争夺，一条阵线只有被A占领，被B占领与中立3种状态.其中缓冲区可以容纳5个单位，前线可容纳4个，指挥阵线在友方缓冲区未被占领时可容纳3个，否则为6个，总部不算单位
### 回合与行动
同KARDS

### 时间线系统
**整个对局有五条时间线 分别为：1930及以前，1931-1950，1950-1990，1991-2050，2050后**
每条时间线有一个对应战场，共五个战场
#### 历史事件系统
双方玩家可以篡改对方在此时间线发生的历史事件从而产生影响
如：美苏和平：关停美苏冷战

**以下是具体事件**
##### 大航海（1930前）
**开启：**
无效果

**关闭：**
友方每回合失去一个行动点
##### 第二次世界大战（1931-1950）
**开启：**
无效果

**关闭：**
本时间段所有友方单位具有+2+2，1950后时间段所有友方单位具有-1-1
##### 美苏冷战（1951-1990）
**开启：**
无效果

**关闭：**
回合开始时若处于本时间段及以后，额外获得2个行动点。1950-2050所有友方单位具有-1-1
##### 第三次世界大战（1991-2050）
**开启：**
本时间段所有友方单位具有-1行动花费，1951-1950时所有友方手牌具有-2花费，2050后所有友方单位具有-3-2

**关闭：**
无效果

### 卡牌种类
**2050前**
#### 步兵
每回合选择移动或攻击一次

**1930-2050**
#### 坦克
一回合可以攻击与行动一次
#### 轰炸机
行动同步兵，攻击时无视距离限制，若该阵线有敌方战斗机，则无法攻击。攻击时不会受到反击伤害，无视“被守护”，被攻击时不会造成反击伤害
#### 战斗机
行动同步兵，攻击时无距离限制
#### 炮兵
同战斗机，攻击时不会受到反击伤害，无视“被守护”

**2050后**
#### 星舰
一回合可以移动3次与攻击一次

### 词条
#### 闪击
具有**闪击**的单位部署后可立即行动
#### 预备
具有**预备**的单位可以直接部署至缓冲区
#### 灵活X
具有**灵活**的单位一回合可以移动X次且可以后退，一个单位最多可以拥有3**灵活**
#### 守护
具有**守护**的单位会使相邻单位获得**被守护**，具有**被守护**的单位不能被单位攻击，**守护**单位不能具有**被守护**
#### 穿梭
具有**穿梭**的牌使用后可以选择并更改当前所处时间线，并触发后续描述
#### 部署
具有**部署**的单位部署时触发后续描述
#### 亡计
具有**亡计**的单位死亡后触发后续描述
